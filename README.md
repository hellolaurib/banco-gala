# Banco GALA

Prototipo de alta fidelidad clicable de **Banco GALA**, construido a partir del diseño en Figma para mostrar el flujo de transferencia de dinero de principio a fin.

- Home → Transferir → Envía → elegir contacto → monto → verificación → confirmación → éxito → estado de la transacción.
- React 19 + Vite + Tailwind v4.
- Deploy: GitHub Pages.

## Desarrollo

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run deploy
```

> Algunas pantallas del final del flujo (Verificación, Confirmación, éxito y estado) todavía estaban vacías en el archivo de Figma de origen (solo el shell "Verificación") — se completaron aquí con contenido representativo para que la demo sea navegable de principio a fin.
